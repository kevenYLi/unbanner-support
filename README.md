# Unbanner – Support

<img src="docs/icon.png" width="96" alt="Unbanner icon">

**Unbanner for Safari** removes “Open in App” pop-ups and banners on iPhone and iPad, and keeps links in Safari instead of jumping into apps.

This repository is for **support and feedback only** (the app's source code is not here).

- 📖 FAQ & help: https://kevenyli.github.io/unbanner-support/
- 🐞 Report a site that still nags you, a broken page, or request a site: [open an issue](../../issues/new/choose)
- ✉️ Prefer private? Email **unbanner.help@outlook.com** — or use the button inside the extension (Safari → Unbanner icon → “Report this site”), which fills in the page address for you.
- 🔒 [Privacy policy](https://kevenyli.github.io/unbanner-support/privacy.html)

> Issues are public. Please don't post links or screenshots that contain personal information.

### What Unbanner can't do

Unbanner only works on web pages in Safari. It can't help with:

- Apps opening other apps (a “shake your phone” or splash ad inside an app that jumps to a shopping app).
- Web pages opened inside other apps (WeChat, QQ, Weibo…) or in other browsers such as Chrome.
- Content the website never sends to the browser: a document that only shows a few pages, low-quality-only video, a login wall. Unbanner removes the prompts but can't bring back content that isn't there.
- Pages that are nothing but a “download our app” page.
- The “Open in the … app” banner Safari itself shows when the app is installed.

Please don't open issues for these — but if you're not sure, ask anyway.

### 插件管不了的情况

插件只在 Safari 的网页里工作，下面这些管不了：

- App 跳 App：比如 App 里的「摇一摇」、开屏广告跳到淘宝、京东。
- 在微信、QQ、微博等 App 里打开的网页，以及 Chrome 等其他浏览器。
- 网站压根没发给网页的内容：比如文档只给看几页、视频只给低清、要登录才能看。插件能去掉提示，但变不出网页里本来就没有的内容。
- 整页就是「下载 App」的页面。
- 装了 App 后 Safari 自己显示的「在“…”App 中打开」横幅。

这些情况就不用提 issue 了；拿不准的话，照样欢迎来问。
